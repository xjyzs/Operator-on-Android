如何使用

1° 下载安装

前往 Releases 下载符合你设备的 APK：
• 一般设备 (Android 8.0+) 下载 Minsdk26
• Android 10+ 下载 Minsdk29
• Android 15+ 下载 Minsdk35
• 如果不清楚，请直接下载 universal 通用版。

2° 授予权限并配置 API

先按照提示授予必要权限，
再填入模型提供商的 URL、Key 以及 模型名称。

3° 开始使用

回到主页，点击下方的输入框，开始尽情使用吧！

常见问题

Q: 为什么 Shell 权限无法授予?
A: 此应用需要你的设备已 Root或已安装 Shizuku 并激活

Q: 为什么 AI 在某些应用(如微信)无法输入文字?
A:: 应用可能不支持非 Talkback 的无障碍应用, 可尝试关闭虚拟屏功能

Q: 使用什么 AI API?
A: 本工具支持 绝大多数 OpenAI 格式的 API, 只要模型支持视觉(识图)即可
